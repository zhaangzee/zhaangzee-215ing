# 金融底层逻辑学习框架（以黄金为锚）

## Overview

把用户零散的金融知识梳理成一套**可内化**的底层认知框架：以黄金为入口，沿「机会成本（实际利率）→ 美元 → 信用风险/央行购金」这一条根，解释宏观数据与资产价格的关系；并用「反常案例 + 自测题 + 相似题重测」对抗遗忘。

本 skill 提供：① 完整知识底稿（`references/finance_logic.md`）；② 一个已实测可用的可交互学习网页模板（`assets/finance-logic-framework.html`）；③ 一套教学法，用于生成或扩写同类学习框架。

## 何时使用

- 用户说「想系统学金融 / 看不懂黄金为什么涨跌 / 帮我梳理底层逻辑」。
- 用户要求「做个学习框架 / 每节出题自测 / 答错再出相似题」。
- 用户发来财经事件（CPI、非农、美联储、地缘、央行购金）想用框架分析。
- 用户想把某份资料（如桌面的《黄金底层驱动逻辑与实战判断》）整理成可学习的结构。

## 核心认知模型（先内化这条根）

**黄金价格 = 机会成本 + 保险价值**
- 机会成本 ← 美债实际收益率（TIPS）方向 → 主链
- 保险价值 ← 美元信用 / 风险事件 / 央行购金 → 长周期底部

一句话：**中短期看「实际利率 + 美元」，长周期看「信用 + 央行购金」。** 一切宏观指标都只是改变实际利率/美元/信用预期的「入口」，不是直接原因——这是框架的灵魂，所有解释都回到这一点。

## Workflow

### 任务 A：生成 / 交付可交互学习网页

1. 读取 `assets/finance-logic-framework.html`（已是 6 模块、72 选项、含判断句生成器的完整模板）。
2. 复制到用户工作目录（如 `./金融底层逻辑学习框架.html`），用本地预览或让用户双击打开。
3. 若需**扩写/改题**：以 `references/finance_logic.md` 为唯一事实来源，保持页面「是什么→为什么→反常案例 + 每节 3 题 + 相似题重测 + 进度条 + 判断句生成器」结构不变。
4. **必做健壮性**：`localStorage` 须有 try/catch 内存降级（沙箱 iframe 会禁 localStorage，否则整页空白）；相似题用就近 DOM 定位，勿用全局选择器。

### 任务 B：用框架分析一条财经事件（如 CPI / 美联储 / 地缘）

按 `references/finance_logic.md` 的**实战七步**组织回答：
1. 先定环境（软着陆 / 滞胀 / 衰退 / 信用危机…），再定主链（实际利率 or 美元 or 风险信用）。
2. 用「判断句模板」给结论：在【环境】下，因【矛盾】推动美联储【转鹰/鸽】，实际利率【上行/下行】、美元【…】、风险溢价【…】，故黄金中短期偏【多/空/震荡】。
3. **主动检查五大反转**：本次是否落入反转③（CPI 高黄金跌）或反转④（降息黄金跌）等例外；若是，说明为什么直觉失效。
4. 提示：这是认知框架，非投资建议。

### 任务 C：出题 / 自测 / 带练

- 按每节 3 题生成选择题，每题含：题干、4 选项、正确项下标 `a`、解析 `e`、1–2 道相似题 `sim`（同结构换措辞）。
- 「答对」标绿、「答错」给解析并生成相似题重测，直到吃透——对应模板里的 `submitQ / nextSim` 逻辑。
- 可先在对话里直接问用户那 3 题，答错当场出相似题，再决定是否固化进 HTML。
